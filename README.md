# Bhanu Sai Teja — Cybersecurity Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract `bhanu_cybersecurity_portfolio.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. An internet connection is used only to load Google Fonts; the site otherwise works locally.

## Personalise before publishing
- Confirm the Wipro job title and replace the timeline entry with verified responsibilities.
- Add your email and GitHub profile in the contact section if you want them public.
- Replace or remove any project details that don't exactly match your experience.
- Add photos, project links, and certificates only when ready.

## Publish for free
You can deploy this static site using GitHub Pages, Netlify, or another static hosting provider. Upload the website files (`index.html`, `style.css`, `script.js`, and `profile-photo.png`) to the provider.
